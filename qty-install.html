🧾 수량 대조 설치

마스터 수량 웹에서 당일 발주를 수량과 맞춰 보는 도구입니다. 크롬에서 한 번만 설치하면 됩니다.
1. 아래 초록 버튼을 크롬 즐겨찾기바로 끌어다 놓으세요
즐겨찾기바가 안 보이면 Ctrl + Shift + B
🧾 수량대조
2. 쓰는 법
  1. 수량 웹(service.masterc.co.kr/qty)에 본인 아이디로 로그인합니다.
  2. 수량 웹 화면에서 즐겨찾기바의 🧾 수량대조를 누르면 오른쪽에 패널이 뜹니다.
  3. 처음 한 번: 패널의 📄 발주 시트 칸에 본인 월 시트 주소를 붙여넣습니다. 옆에 ✅ 시트 이름이 뜨면 연결된 것입니다(이 브라우저에 기억됩니다, 달이 바뀌면 새 주소로).
  4. 패널의 📄 가져오기_당일을 누르면 당일 발주와 수량이 자동으로 대조됩니다.
3. 시트 연결 (패널 켤 때마다 한 번)
시트는 본인 크롬에 로그인된 본인 구글 계정으로 읽고 옮깁니다. 다른 사람에게 시트를 공유할 필요는 없습니다.
패널의 🔗 시트 연결을 누르면 작은 창이 뜹니다 → 그 창은 닫지 말고 최소화 → 패널에 ✅ 시트 이름 · 본인 메일이 뜨면 연결된 것입니다.
처음 한 번은 그 작은 창에서 본인 구글 계정을 고르고 허용을 눌러 주세요.
「Google에서 확인하지 않은 앱」 화면이 나오면 [고급] → [수량대조 시트연결(으)로 이동]을 누르면 됩니다(사내 도구라 구글 심사를 안 받았습니다).
시트 모양이 다르면 패널의 ⚙️ 시트 모양을 펼쳐 맞춰 주세요 — 주문 탭 이름, 재고 없는 주문을 옮길 탭 이름, 주문이 시작하는 행, 상품명·성함·주소 열. 기본값은 「당일」·「재고 없음」·8행·J/K/L열입니다.
이 도구는 수량 사이트와 본인 시트끼리만 주고받습니다.
4. (권장) 패널 자동 띄우기 — 감시가 안 끊기게
수량 웹은 검색을 하거나 창고 탭을 누르면 페이지가 새로 뜹니다. 그때 패널과 타이머가 통째로 날아가서, 📌 지금 잡기로 걸어 둔 감시도 같이 멈춥니다. 북마크릿을 다시 누르면 이어받지만, 누르는 걸 잊으면 조용히 끊깁니다.
아래 확장을 한 번 설치해 두면 수량 웹이 뜰 때마다 패널이 저절로 올라옵니다(접어 둔 상태도 그대로).
  1. 크롬 주소창에 chrome://extensions → 오른쪽 위 개발자 모드 켜기
  2. [압축해제된 확장 프로그램을 로드합니다] → C:\work\baljuseo\qty-ext 폴더 선택
  3. 수량 웹을 새로고침하면 패널이 저절로 뜹니다
패널 코드는 늘 최신을 받아 오므로 도구가 업데이트돼도 확장을 다시 설치할 필요는 없습니다. 설치해도 북마크릿은 그대로 쓸 수 있습니다.
⚠️ 꼭 지켜 주세요
  1. 🚀 판정대로 실행(잡기·대기·증량)은 한 사람만 누릅니다. 둘이 같이 누르면 수량이 두 번 잡힙니다. 보기·대조만 하는 건 같이 해도 괜찮습니다.
  2. 패널 제목 옆 버전 글자가 안 바뀌면 옛 화면입니다 — 수량 웹 탭을 새로고침하고 다시 누르세요.
