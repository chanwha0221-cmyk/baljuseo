🦊 여우팀 실 소유자 — 감시 버튼

여우 칸에 수량을 넣으면 «누가 몇 개» 잡았는지 여우팀 수량시트 「실 소유자」에 자동으로 붙여 주는 버튼입니다.

준비물

  • 크롬에 로그인한 구글 계정이 마스터 수량시트 편집 권한을 가지고 있을 것 (「수정 기록」은 편집자에게만 보입니다)
  • 같은 계정이 여우팀 수량시트를 볼 수 있을 것
  • 감시용으로 켜둘 PC 한 대

설치

아래 초록 버튼을 북마크바로 끌어다 놓으세요. 먼저 등록해 둔 같은 이름의 버튼이 있으면 지우고 새로 넣으세요.

🦊 여우 실 소유자

북마크바가 안 보이면 Ctrl + Shift + B

쓰는 법

  1. 마스터 수량시트를 연다
  2. 북마크바의 🦊 여우 실 소유자 클릭
  3. 오른쪽 위에 초록 「대기 중」 배지가 뜨면 끝. 그냥 두면 된다
그 뒤로는 자동입니다. 누가 여우 칸에 수량을 넣으면 1분 안팎에 여우팀 시트 「실 소유자」에 이름이 붙습니다. 평소엔 아무 일도 하지 않습니다.

알아둘 것

  • 이 탭은 감시 전용으로 두세요. 이름을 읽는 동안 탭을 옮겨 다니므로, 같은 탭에서 작업하면 엉킵니다
  • 다른 탭 뒤에 둬도, 창을 최소화해도 계속 돕니다. 이 탭을 보고 있을 필요 없습니다
  • 배지를 클릭하면 멈춥니다. 다시 켜려면 북마크를 또 누르면 됩니다
  • 탭을 닫거나 새로고침하면 감시도 끝납니다 — 버튼을 다시 누르면 됩니다
  • PC를 켜둔 채 퇴근하면 다음 날 아침까지 계속 돕니다
  • 팀원 누구에게 줘도 똑같이 돕니다. 켜두는 사람은 한 명이 제일 빠릅니다 — 두 명이 켜도 결과는 맞지만, 동시에 보내면 한쪽이 다시 읽느라 늦어집니다

안 될 때

  • 「아무 칸이나 오른쪽 클릭…」이 뜨면 시트가 덜 열린 것입니다 — 몇 초 뒤 다시 누르거나, 아무 칸 오른쪽 클릭 → Esc 한 뒤 누르세요
  • 「마스터 수량시트를 열고 눌러 주세요」가 뜨면 다른 시트에서 누른 것입니다
  • 배지가 빨간색이면 오류입니다 — 새로고침하고 2·3번을 다시 하세요
