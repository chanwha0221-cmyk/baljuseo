 · 로그인은 각자 본인 구글 계정으로 (그 계정이 우리 팀 시트에 편집 권한만 있으면 됨)
 · 첫 로그인 때 '확인되지 않은 앱' 경고가 뜨면 → 고급 → 계속 누르면 됩니다

2️⃣ 반영 시트 — 우리 팀 유통시트 주소(URL/ID)를 아래 반영 시트 칸에 넣기 (필수) (⚠️ 안 넣으면 각 시트 적용이 막힘 — 한 번 넣으면 계속 유지됨)
3️⃣ 링크 시트 — 우리 팀 '최신 링크 모음' 구글시트 주소를 아래 링크 시트 칸에 넣기 (필수 — 안 넣으면 링크 업데이트·각 시트 적용 막힘)

📖 이 도구가 하는 일

변동공지 원본 시트에서 아직 우리 팀 시트에 반영 안 한(=동그라미 표시가 없는) 상품 변경사항을 뽑아서, 우리 팀 유통시트의 각 탭(상품변동사항·당일생물·창고)에 자동으로 넣어주는 도구예요.
순서만 지키면 클릭 몇 번으로 끝나요 → 세팅(처음 1회) → 매일: 불러오기 · 확인 · 각 시트 적용.

⚙️ 처음 한 번만 — 세팅

화면 위 ⚙️ 설정을 펼쳐서 아래를 채우세요. 한 번 넣으면 저장돼서 계속 유지돼요.

1. Client ID (구글 로그인)

손대지 마세요. 모든 팀 공용이라 이미 세팅돼 있어요. 로그인은 각자 본인 구글 계정으로 하고, 처음 로그인 때 '확인되지 않은 앱' 경고가 뜨면 고급 → 계속을 누르면 돼요. (본인 계정이 우리 팀 시트에 편집 권한만 있으면 됩니다.)

2. 반영 시트 (필수)

결과를 넣을 우리 팀 유통시트 주소(URL이나 ID)를 넣고 저장.
⚠️ 안 넣으면 각 시트 적용이 막혀요.
⚠️ 변동공지를 '읽어오는' 원본 시트를 넣으면 안 돼요(에러남) — 결과를 '쓸' 유통시트를 넣으세요.

3. 링크 시트 (필수)

우리 팀 '최신 링크 모음' 구글시트 주소를 넣고 저장. 그 시트에 '링크'라는 이름의 탭이 있어야 해요 (그 탭 A열=상품명, B열=URL을 읽어서 상품명에 링크를 걸어줍니다).

4. 내 표시 열 ⭕

원본 시트에서 '반영 완료' 동그라미를 치는 열을 넣으세요. 팀마다 달라요 (예: S, 마우팀 X). 이 열에 동그라미가 없는 상품만 '아직 안 한 신규'로 가져옵니다. (필수 — 안 넣으면 불러오기가 안 돼요.)

5. 🔎 시트 탐색 (추천)

누르면 반영 시트의 탭 목록이 나와요. 탭마다 '변경값을 몇 행부터 넣을지'를 지정할 수 있어요 (팀마다 헤더 위치가 다르니까). 비워두면 기본값으로 들어가요.

🛠 매일 쓰는 순서

① 원가 파일 선택 — 리모컨(원가) 엑셀을 넣어요. (상품명→원가·현재판매가 준비)
② 시작 행 넣고 🔍 불러오기 — 그 행부터 동그라미 없는 신규가 표로 나와요.
· 끝 행: 넣으면 그 행까지만 (내일 오전에 올릴 상품 위에서 끊을 때).
③ 표 확인·수정 — 공급가·변동·마감시간·스펙변동을 칸에서 바로 고칠 수 있어요.
· ✕로 뿌리기 싫은 상품 빼기 → 아래 '제외된 상품'에서 ↩로 다시 올리기.
④ 🔀 각 시트 적용 — 상품변동사항·당일생물·창고 탭에 자동으로 들어가요.
· 창고 공급처를 어느 탭에 넣을지 모르면 물어봐요 (한 번 답하면 저장).
· <○○창고 전상품> 택배사 변경 행은 상품으로 안 넣고, 창고 탭에서 그 창고 상품들의 택배사를 실제로 바꾸고 스펙에 변경 문구를 달아줘요.
⑤ (선택) 📗 엑셀 생성 — 리모컨 업데이트용 변경분만 엑셀로 뽑아요.
⑥ (선택) 🔗 링크 업데이트 — 링크 시트 + 그룹웨어 문서복사를 새 창으로 열어줘요.

❓ 자주 묻는 것 · 주의

Q. 각 시트 적용했더니 "HTTP 400" / "탭에 못 썼어요"?
→ 반영 시트에 잘못된 주소(읽는 원본)를 넣었거나 탭이 없어서예요. 결과를 쓸 유통시트가 맞는지 확인.

Q. "○○ 공급처는 어느 탭?" 하고 물어봐요.
→ 공급처 이름과 창고 탭 이름이 다를 때예요 (예: 공급처 단독(유) → 탭 단독). 탭 이름을 정확히 입력하면 다음부턴 안 물어봐요.

Q. 원가 정보가 업체한테 보이면 안 되는데?
→ 스펙변동에 '원가'가 들어간 내용은 각 시트에 넣을 때 자동으로 빠져요. 화면엔 보여도 시트엔 안 들어가요.

Q. 여러 명이 동시에 써도 돼요?
→ 팀마다 다른 시트라 서로 무관해요. 단 같은 팀이 같은 시트에 동시에 '각 시트 적용'은 피하세요(한 번에 한 명).
