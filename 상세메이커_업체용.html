🎨 상세 메이커

유통시트 상품 링크 → 페이지 소스 붙여넣기 → 상세페이지 자동 생성 (JPG·HTML 출력) v2.1 업체용
⓪ 카탈로그에서 상품 고르기 (고르면 아래가 자동으로 채워집니다)
① 페이지 소스 붙여넣기
상품명 (상세 제목·썸네일 파일명 공통 — 생성 시 자동)
② 브랜드명 (헤더·푸터 공통)
③ 사진 선택 (클릭 on/off · 드래그 순서 · 첫장 히어로)
④ 썸네일 추출 (1000×1000 · 어디든 공용)
소스를 붙여넣고
[⚡ 상세페이지 생성]을 누르세요
❓ 상세 메이커 사용법
상품 페이지 소스만 붙여넣으면 상세페이지가 자동으로 만들어져요. 아래 순서대로만 하시면 됩니다.
🔐 처음 한 번 — 이메일 인증
마스터에 등록된 이메일 입력 → [인증메일 받기] → 메일로 온 6자리 입력 → 끝.
인증은 6시간 유지되고, 지나면 같은 방법으로 다시 받으면 돼요. (메일이 안 오면 스팸함 확인!)
1️⃣ 상품 소스 복사
유통시트에서 팔 상품의 링크 클릭 → 상품 페이지가 열리면
Ctrl+U (페이지 소스 보기) → Ctrl+A (전체 선택) → Ctrl+C (복사)
2️⃣ 상세페이지 생성
왼쪽 ① 페이지 소스 붙여넣기 칸에 Ctrl+V → [⚡ 상세페이지 생성] 클릭 → 오른쪽에 미리보기가 뜹니다.
"인식 실패"가 뜨면? 게시판 목록이 아니라 상품 상세 페이지에서 Ctrl+U 했는지 확인하세요.
3️⃣ 내용 다듬기
· ② 브랜드명에 우리 가게 이름 입력 (상세 위아래에 들어가요)
· ③ 사진: 클릭=켜고 끄기 / 드래그=순서 바꾸기 / 첫 장이 대표 사진
· 사진 많으면 [🧹 비슷한 사진 자동 거르기] 한 번
· 문구 고치고 싶으면 [✏️ 수정] 누르고 미리보기에서 직접 타이핑
4️⃣ 저장 — 이게 제일 중요!
📱 JPG 분할 저장 (추천) — 여러 장으로 나눠 받아져요. 쇼핑몰 상세 이미지 칸에 파일명 순서대로(1of4 → 4of4) 전부 올리면 한 장처럼 이어져 보입니다. 휴대폰에서 안 깨져요.
🖼️ JPG 한 장 — PC·인쇄용. 긴 상세는 휴대폰에서 깨질 수 있어요.
📋 HTML 복사 — 홈페이지에 HTML 코드 넣을 줄 아는 분만.
브라우저가 "여러 파일 다운로드 허용"을 물으면 허용을 눌러주세요.
5️⃣ 썸네일(대표이미지)
④ 썸네일 추출 누르면 1000×1000 정사각 이미지가 나와요 → 쇼핑몰 대표이미지 칸에 올리면 됩니다.
